## Debug Adapter Protocol

The protocol model, request and response names, event names, type names, and
many doc comments are derived from Microsoft's
[Debug Adapter Protocol](https://microsoft.github.io/debug-adapter-protocol/)
specification.

licensed under Creative Commons Attribution and its code is licensed under the
